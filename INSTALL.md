# TAS Studio 0.3.3

Requires IGTAP with the Recharge mod loader already installed.

1. Close the game.
2. Move any previous TAS Studio folder (Tas.Studio or igtap.tas) outside Recharge/Mods as a backup. Keep its data there if you want to preserve recordings. Do not leave two copies of this mod in Mods.
3. Extract this ZIP into the game's Recharge/Mods folder. The manifest should be at Recharge/Mods/Tas.Studio/mod.json.
4. Start the game. Open TAS Studio with F5. The main menu offers Load Tas, Start Replay and Create New Tas.

While recording: F6 pauses/resumes, F7 steps, F8 stops, and F9 opens named replay checkpoints. Pause before saving or loading a checkpoint. Checkpoints reconstruct state by replaying; they are not instant memory snapshots.

This package contains the mod, Harmony dependency and license, and documentation. It contains no recordings, checkpoints, user settings, game save data, logs, source code, development tools, or game assemblies. Data folders are created when the mod runs.
